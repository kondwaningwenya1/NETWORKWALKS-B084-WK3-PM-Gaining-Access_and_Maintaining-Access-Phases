# Week 3 Project: Password Cracking

## Overview

This repository contains my Week 3 Cybersecurity & Ethical Hacking practical project. The project focuses on password cracking using two different approaches: **John the Ripper (JTR)** and **Networkwalks online tools**.

The objective was to understand how password cracking works, how password hashes are extracted from protected PDF documents, and how cracking tools can be used to recover passwords.

## Project Modules

### Module 1: Password Cracking with John the Ripper (JTR)

This module involved using John the Ripper and its graphical interface, Johnny, to recover the password of a protected PDF document.

**Tools Used:**
- John the Ripper (JTR)
- Johnny (JTR Graphical User Interface)
- Online Hash Extractor
- Windows Notepad



### Module 2: Password Cracking with Networkwalks Tools

This module involved using Networkwalks' online tools to extract a PDF hash and recover its original password.

**Tools Used:**
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Web Browser


## Key Concepts Learned

Through these practical exercises, I gained experience and understanding of:

- Password cracking techniques.
- Password hash extraction.
- The difference between hashing and encryption.
- Using John the Ripper and Johnny for password recovery.
- Using browser-based password-cracking tools.
- The importance of strong and complex passwords.
- The security risks associated with weak passwords.

## Conclusion

This project provided practical experience in password cracking using both locally installed and browser-based tools. By completing the two modules, I gained a better understanding of how password hashes are extracted and how cracking tools attempt to recover passwords.

The exercises also demonstrated why users should create strong, unique passwords to protect sensitive information.
